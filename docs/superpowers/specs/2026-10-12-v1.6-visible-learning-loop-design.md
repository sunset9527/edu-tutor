# EduTutor v1.6 前端学习闭环与可解释过程设计

## 1. 目标与边界

v1.6 将 v1.5 已具备的记忆和学习状态能力变成可观察、可恢复、可操作的产品流程。范围对应产品路线图 9.1～9.4。

知识编译继续由 CLI 执行。异步编译任务、教师端和完整浏览器端自动化留在后续版本。

## 2. SSE 对话事件

保留 `POST /api/chat` 兼容接口，新增 `POST /api/chat/stream`。前端使用 `fetch` 发送 JSON 和 JWT，再读取响应流；不使用只能发 GET 且不方便携带 Authorization 的原生 `EventSource`。

每个 SSE 帧使用：

```text
event: <event_type>
data: <json>

```

公共字段为 `sequence`、`session_id` 和 `timestamp`。正常事件顺序：

1. `generation_started`
2. `memory_retrieved`
3. `response_chunk`，可重复，来自 LLM 原生流式响应
4. `messages_saved`
5. `memory_extracted`
6. `profile_updated`
7. `completed`

异常时发送 `failed` 并结束流。`memory_retrieved` 返回本轮采用的记忆及评分追踪；`memory_extracted` 返回候选、实际写入数、新建记忆和更新记忆；前端据此区分“本轮命中 / 本轮新建 / 本轮更新”。

非流式 LangGraph 工作流继续用于兼容和离线测试。流式服务复用相同的历史加载、提示词、消息落库、提取和存储规则，避免形成第二套业务语义。

## 3. 会话恢复

新增 `GET /api/sessions/{session_id}/messages`，返回会话归属、状态和按 ID 正序排列的消息。学生 store 按学生把最近会话 ID 写入 `localStorage`。页面刷新后读取该 ID，再从 MySQL 恢复消息；404 或已失效时清除本地 ID。

“新会话”先调用现有结束会话接口生成摘要，再清除当前会话。用户可继续使用非流式接口，恢复逻辑与传输方式无关。

## 4. 学习事件与真实报告

新增 `learning_events` 表，字段包括学生、事件类型、来源类型/ID、知识点、JSON 载荷和发生时间。记录以下事实：

- `mastery_changed`
- `wrong_question_added`
- `wrong_question_mastered`
- `review_succeeded`
- `review_failed`

错题、掌握状态、复习计划和事件记录在同一 MySQL 事务中提交。报告时间序列只聚合这张事实表，不从当前最终状态反推历史。每个数据点返回参与计算的 `event_ids`，使数字可以回到数据库记录。

时间序列按自然日输出：掌握度变化次数、错题新增/掌握数、复习成功/失败数和当日复习完成率。表上线前没有事件的数据保持空，不补造历史。

## 5. API 与展示调整

### 后端

- `GET /api/students/{id}/memories` 支持 `memory_type`、`page`、`page_size`，返回 `items/total/page/page_size`。
- 记忆项补充 `last_accessed_at`、`last_reviewed_at`、`status`。
- 个性化路径补充最近待复习日期。
- `GET /api/knowledge/subjects` 从知识点表返回真实科目列表。
- 学习报告补充 `timeline`，每个数据点带事件 ID。

### 前端

- 对话页逐条显示真实 SSE 阶段和流式回答；侧栏分组展示命中、新建、更新。
- 记忆页由后端执行类型筛选和分页。
- 遗忘曲线读取当前 `decay_lambda`，以所选记忆的真实强度和最后复习/创建时间为起点。
- 图谱页读取真实科目，路径卡显示推荐原因、掌握度、错题数和预计复习日。
- 报告页绘制来自 `learning_events` 的真实时间序列，并在 tooltip 中展示记录 ID。
- 练习页继续由学生点击“我错了”确认入错题本；复习页继续由学生确认成功或失败，这两类确认都会产生事件。

## 6. 数据库迁移与兼容

新增一条 Alembic 迁移创建 `learning_events`。迁移不回填历史数据。现有接口的账号隔离规则继续使用；新增会话、事件和分页接口都先校验学生或会话归属。

`POST /api/chat` 响应保持不变。记忆列表响应从数组变为分页对象，仓库内所有调用点同步升级。

## 7. 测试与证据

先建立失败测试，再实现：

1. SSE 帧编码、事件顺序、回答分片、失败帧和会话 ID。
2. 会话消息恢复和跨账号 404。
3. 记忆类型筛选、分页边界和账号隔离。
4. 学习事件原子写入、报告聚合和 `event_ids` 回溯。
5. 科目列表与个性化路径复习日期。
6. 前端 SSE 解析、会话持久化、动态遗忘曲线和报告序列转换。
7. 后端全量离线测试、前端测试、类型检查、生产构建和向量一致性审计。

交付 `docs/releases/v1.6/sse-contract.md`、`demo-script.md`、`acceptance.md` 及一份可复现事件样例。在线 LLM 质量和网络断线重连压力测试不计入离线门禁，并在验收报告中明确标注。
