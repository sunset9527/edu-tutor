## 第1章 绪论

### 1.1 研究背景与意义
- 大语言模型（LLM）智能体缺乏跨会话记忆：每次对话都是"失忆的陌生人"
- 个性化教育辅导场景：长期多会话关系，短期上下文不足以支撑个性化
- 记忆增强是当下研究热点（MemGPT、Generative Agents、Mem0 等），教育是记忆技术的天然落地场景
- 意义：理论（记忆生命周期管理方法）+ 应用（AI 辅导老师产品化）

### 1.2 国内外研究现状（相关工作，答辩必问）
| 工作 | 核心思想 | 与本文差异 |
|------|---------|-----------|
| MemGPT（虚拟上下文管理） | 分层内存 + 函数调用管理上下文 | 本文聚焦跨会话长期记忆 + 教育画像 |
| Generative Agents（斯坦福 AI Town） | 记忆流 + 反思 + 计划 | 本文引入艾宾浩斯遗忘曲线与知识图谱双引擎 |
| Mem0 | 记忆提取/存储/检索通用框架 | 本文面向教育场景的领域化记忆设计 |
| LangGraph Memory/Store | 官方持久化方案 | 本文在其上自研提取/遗忘/关联逻辑 |
| 传统 RAG | 每次查询重新检索文档 | 本文用 LLM Wiki 编译互链知识图谱（编译一次） |

### 1.3 研究内容
1. 记忆生命周期管理：提取→存储→检索→更新→遗忘 五阶段方法
2. 艾宾浩斯遗忘曲线驱动的检索加权与复习调度（SM-2 简化模型）
3. 双引擎架构：学生侧记忆引擎 + 学科侧知识引擎（LLM Wiki）协同
4. 系统实现与评测（四组实验）

## 第2章 相关技术

1. **LangChain / LangGraph**：工作流编排、checkpointer 持久化、1.x 新 API
2. **向量数据库（ChromaDB）**：语义检索、余弦相似度、metadata 过滤
3. **BGE-M3 中文向量模型**：多语言、1024 维
4. **艾宾浩斯遗忘曲线**：R = e^(-t/S)，SM-2 间隔重复算法
5. **LLM Wiki 模式**（Karpathy）：编译一次、互链知识库（对比 RAG 每次检索）

## 第3章 系统设计

### 3.1 需求分析
- 功能需求：个性化辅导对话、学生画像、记忆管理、复习调度、知识图谱
- 非功能需求：跨会话记忆一致性、可解释（溯源）、数据可评测

### 3.2 总体架构（双引擎）
```
教育辅导智能体（LangGraph 编排）
├── 记忆引擎（学生侧）：提取→存储→检索→更新→遗忘
├── 知识引擎（学科侧）：PDF 课本 → LLM Wiki 编译 → 互链知识点图谱
└── 双引擎桥：记忆关联知识点（knowledge_point_id）
```

### 3.3 记忆引擎设计
- 四层记忆模型：短期/情景/语义/程序
- 五阶段生命周期（详细设计见系统设计文档 §3）
- 遗忘曲线算法：strength ∈ [0,1]、SM-2 简化、检索权重 w = strength × e^(-λt)

### 3.4 知识引擎设计
- LLM Wiki 编译管线：PDF → 文本块 → LLM 抽知识点（wikilinks）→ 落库
- 图谱：113 节点 / 223 边 / 连接率 92.9%（人教版数学七上）

### 3.5 数据库设计
10 张表：students/sessions/messages/memories/memory_conflicts/student_profile/knowledge_points/knowledge_point_links/wrong_questions/review_plans

## 第5章 实验与评价（核心章节，数据已就绪）

### 5.1 实验设计
四组实验，全部可复现（python scripts/eval/run_eval.py）：

### 5.2 实验一：记忆提取质量
- 数据集：15 轮标注辅导对话（gold 记忆标注）
- 指标：精确率/召回率/F1
- **结果（3 次均值）：P=0.623, R=0.717, F1=0.667**\n- 方法：提取后二次校验（LLM 过滤教学内容类误提取），比无校验基线 F1=0.546 提升 +0.12\n- 分析：召回与精确率均衡；发现 LLM 自报置信度不可靠（阈值过滤无效）、小样本评测噪声 ±0.1（多次均值稳健化）

### 5.3 实验二：记忆检索效果
- 数据集：10 条 ground truth 记忆 + 12 条查询
- 指标：Hit@3 / MRR
- **结果：Hit@3=1.000, MRR=0.730**
- 分析：全命中 top-3，语义检索可靠；MRR 显示首个相关记忆平均在 1.37 位

### 5.4 实验三：消融实验（核心）
- 方法：6 场景（5 有历史 + 1 新学生）× 有记忆/无记忆两组回答 × LLM-as-judge 打分（1-5）
- **结果**：

| 维度 | 有记忆 | 无记忆 | 差值 |
|------|--------|--------|------|
| 个性化程度 | **4.33** | 1.50 | +2.83 |
| 连贯性 | **5.00** | 4.00 | +1.00 |
| 正确性 | **4.83** | 4.67 | +0.17 |

- 分析：记忆显著提升个性化（+2.83）；5/6 场景有记忆胜出；新学生场景两模式打平（验证效果来自记忆而非 prompt 差异）

### 5.5 实验四：遗忘机制验证
- 方法：SM-2 复习序列模拟 + λ 对比
- **结果**：30 天后保留率 复习 0.0498 vs 不复习 0.0299；复习后强度 0.6→1.0
- 分析：间隔复习有效减缓遗忘；λ 越大遗忘越快（参数可调）

### 5.6 实验小结
记忆增强系统有效：检索可靠（Hit@3=100%）、个性化显著提升（+2.83）、遗忘机制符合认知规律。

## 第6章 总结与展望

- 总结：记忆生命周期管理方法有效，双引擎架构可行
- 不足：提取精确率待优化、评测规模有限（15 对话/12 查询/6 场景）、未做真实用户实验
- 展望：置信度过滤、跨会话评测扩大、产品化（账号/出题/多学科）、多模态
