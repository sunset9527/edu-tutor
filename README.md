# EduTutor — 个性化教育智能体（毕设）

基于 LangChain/LangGraph 的智能体记忆增强系统——以个性化教育辅导为例。

> 毕设 + 产品双定位。系统设计见 `E:\个人发展\002职业\项目4：个性化教育\个性化教育-系统设计.md`，
> 版本规划见同目录 `个性化教育-产品迭代路线图.md`。

## 已实现

### v1.5 — 记忆智能与个性化路径（2026-10-12 完成）

- 🔎 **可解释检索**：向量相似度、新近度、遗忘保留率和置信度统一评分；权重与三路限额可配置，追踪记录候选分项、最终排名和未采用原因。
- ♻️ **记忆更新与整合**：练习结果驱动 `不懂 → 基本会 → 熟练 → 精通` 状态机和知识点复习计划；相同有效策略达到证据阈值后才激活为 procedural 记忆。
- 🧾 **跨会话可追溯**：记忆保存来源会话、消息 ID、提取版本和模型；结束会话时生成确定性摘要及情景记忆；MySQL 消息是 LangGraph 唯一恢复来源。
- 🧭 **个性化学习路径**：同时依据图谱前置边、掌握度、薄弱点、未掌握错题和到期复习生成路径，每一步返回原因和数据库证据；证据不足时明确返回缺口。
- ✅ **验收证据**：55 项后端离线测试、前端类型检查/生产构建和双库一致性审计通过；三学生九会话报告及检索追踪见 `docs/releases/v1.5/`。

### v1.4 — 核心正确性与真实性基线（2026-10-12 完成）

- 🧠 **循环复习状态机**：未复习记忆从创建时间衰减，复习记录真实时间，成功后继续生成 2/4/8… 天待办。
- 🧩 **事实槽位冲突**：多个薄弱点允许并存；单值事实和同知识点互斥状态保留可审计冲突记录。
- 🔄 **MySQL/Chroma 一致性**：新增/编辑/归档/冲突均同步向量，失败执行回滚或补偿；审计修复后四类问题均为 0。
- 🔐 **账号隔离**：学生、会话、记忆、复习计划、错题和报告统一验证 token 归属，跨账号访问返回 404。
- 🖥️ **前端闭环修复**：报告页读取真实汇总，图谱详情提供学习路径入口，`vue-tsc --noEmit` 成为构建门禁。
- ✅ **验收证据**：36 项后端离线测试、前端类型检查和生产构建通过；详见 `docs/releases/v1.4/acceptance.md`。

## 快速启动

```bash
cd backend
# 1. 配置 .env（MySQL 已默认 root/123456；填 DEEPSEEK_API_KEY）
# 2. 建库 + 迁移
python scripts/create_db.py
alembic upgrade head
# 3. 编译知识库（可选，知识引擎）
python scripts/build_knowledge.py "<教材PDF路径>" --subject 数学 --grade 初一
# 4. 启动前端（终端2）
uvicorn app.main:app --reload --port 8000
cd ../frontend && npm run dev   # 前端 http://localhost:3000
# 5. 测试
pytest
```
